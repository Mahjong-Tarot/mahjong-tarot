1

Define

What exactly are we fixing?

Every section of every chapter must be accurate to Taoism, brief, and clear enough to survive machine translation. The applications that follow each chapter must meet the same standard and stay true to Taoist principles.

Key terms

  • Couplet: Bill's shorthand for each section of a chapter, whether it's 1, 2, or 3 lines.
  • Accuracy: Taoist and simple. Every line aligns with the three core principles: wuwei (effortless action), ziran (spontaneous naturalness), wuzhi (direct, non-conceptual knowing). No Confucian drift, no modern self-help language. Correct grammar and spelling.
  • Brevity: Same length or shorter than a standard version (e.g., Legge). Never rambling.
  • Clarity: Clear, modern prose with no logic errors, and the meaning survives a multi-language round-trip translation.

Structural decisions already made

  • Keep chapter titles. No section headers (e.g., "The Nature of Dao" is removed).
  • Keep the Background paragraph that follows each chapter's applications.
  • Keep the thematic groupings; chapters are not in traditional order.
  • Move the table of contents to the end of the book, with a note that classifying the chapters is un-Taoist, offered only for readers who want it.
  • Redraft the front matter ("About this rendering") to match these changes.
  • Fix the "te → De" find-and-replace corruption (e.g., "compleDe", "staDe") as a silent pre-pass.

3

Design

What steps does the editor follow, in order?

A. Couplet loop (for each couplet in the chapter)

  1. Read the couplet.
  2. Accuracy: Is it Taoist and simple? If there is the slightest doubt, pull the original characters with literal and figurative definitions and work out a better phrasing from them.
  3. Brevity: Is it the same length or shorter than Legge? If longer, tighten it.
  4. Clarity: If there is any doubt, run the round-trip test:
    English→Russian→Thai→Swahili→English
    Run live through Google Translate (scripted). Pass = the final English faithfully means the same thing (not word for word). Fail = rewrite and test again.
  5. Log the result, highlight any change in the text, and move to the next couplet.

B. Chapter check (after all couplets)

  1. Re-read the whole chapter. Confirm the changes don't break the flow and the logic holds together.
  2. Check the 2–5 applications against accuracy, brevity, and clarity, and confirm each one aligns with Taoist principles. Follow Bill's format: a bold lead phrase, then direct advice.
  3. Check the Background paragraph against the same three standards.
  4. Placement: Does this chapter belong in its current thematic group? If not, recommend where it should move (don't move it; Bill decides). Flag numbering errors the same way.

C. Then

Move to the next chapter. Repeat until every chapter in scope is done.

4

Deliver

How do we run it?

  1. Lock the file. Dave exported the current Google Doc to markdown on October 12. That export is the locked source.
  2. Work on a copy. The AI writes an edited copy plus a review log to context/source-material/tao-te-ching/edited/, one commit per chapter so each change can be diffed. Changes are marked with <mark> in the edited copy. The original stays untouched.
  3. Plan check first. Paste this plan and ask: "Review this plan. Tell me anything unclear or missing before we start."
  4. Run one chapter as a pilot (Ch. 17). Bill reviews it against his own standard before the rest runs.
  5. Execute: "Execute this plan until it's done." High effort setting.
  6. Bill reviews the flagged items in the log. That's where his judgment matters most.
5

Done

How does the AI know it's finished?

Every couplet and every application is marked one of:

✅ Passes, no change  ✏️ Changed with confidence  ⚠️ Changed, needs Bill's review

Final deliverables

  • Edited copy of the book, with structural changes applied (titles kept, no section headers, TOC at the end, front matter redrafted) and every change highlighted.
  • Review log: every couplet, application, and background marked ✅ / ✏️ / ⚠️; every ⚠️ item with original text, new text, which test failed, and why.
  • Placement recommendations: any chapter that should move to a different thematic group, plus numbering errors.
  • A one-line confirmation that every chapter in scope was reviewed.
