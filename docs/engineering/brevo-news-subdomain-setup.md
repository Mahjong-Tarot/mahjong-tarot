4. Click **Add** for each of the 3 required records above. For each:
   - Set **Type** to TXT or CNAME as listed
   - Set **Name** exactly as listed (just the part before `.mahjongtarot.com`)
   - Set **Value** exactly as listed (copy-paste — no trailing dots, no quotes around it)

## Why the parent DMARC is enough

Parent record: `v=DMARC1; p=none; rua=mailto:rua@dmarc.brevo.com`

DMARC subdomain inheritance rules: if the parent record has **no `sp=` tag**, subdomain policy = parent policy. Yours has no `sp=`, so `news.mahjongtarot.com` inherits `p=none` and the same reporting address. No extra DMARC record needed for the subdomain.

You may still want to publish a dedicated subdomain DMARC later if you want to tighten marketing's policy (`p=quarantine` or `p=reject`) independently of transactional — but **don't do this on day 1**. Run `p=none` for 30–60 days first to see reports.

## Troubleshooting

| Symptom | Likely cause | Fix |
|---|---|---|
| `dig` returns nothing for `news` TXT | DNS not propagated yet | Wait 5 min, try again |
| `dig` returns the record but Brevo verify fails | Trailing whitespace or wrong value | Re-copy value from this doc; check Vercel saved it exactly |
| CNAME shows old/wrong value | Vercel auto-prefixed apex | Remove `.mahjongtarot.com` suffix from Name if Vercel added it |
| `brevo-code` TXT exists but Brevo says not found | Brevo's check runs against authoritative NS, not resolver cache | Wait 10–15 min for full propagation |
| DKIM CNAME blocked by Vercel | Vercel sometimes flags root-level magic names | Open Vercel support OR use TXT-form DKIM (Brevo can issue alternate records) |
